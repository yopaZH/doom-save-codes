# DOOM Password Generator

A tool for generating and decoding classic DOOM save passwords. All password handling runs locally in the browser.

## Supported games

- DOOM for PlayStation and Sega Saturn
- Final DOOM for PlayStation
- DOOM 64 for Nintendo 64 (levels 1–32)

## Run locally

Open `index.html` in a modern browser. No server, build step, or dependencies are required.

## Project structure

- `index.html` — page structure and controls
- `assets/styles.css` — layout, colors, and Windows 95 inspired controls
- `assets/app.js` — password encoding, decoding, and form behavior

## References

The app links to password mechanics references and algorithm analyses in its footer, including the DOOM 64 Password Editor source used as an algorithm reference.
