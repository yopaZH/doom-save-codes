What the password stores

Level, difficulty, health, armor and armor type, collected weapons, four ammo counts, and backpack status. DOOM 64 passwords also store the Demon Key artifacts. Some values round up to fixed steps when the game loads the password.

Why some codes are rejected

Each game has its own password format. DOOM and Final DOOM share a system, but use different level ranges. DOOM 64 uses a separate 16-character system; this mode supports original N64 levels 1–32.
