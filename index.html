What a password saves

Passwords store your level, difficulty, health, armor, weapons, ammo, and backpack. DOOM 64 also records Demon Key artifacts. Health, armor, and ammo use fixed steps, so the game may restore a nearby value instead of the exact number entered here.

Choose the matching game

PlayStation and Sega Saturn DOOM share a password format. Final DOOM uses the same format with its own level range. DOOM 64 uses a separate 16-character format for the Nintendo 64 release, with levels 1–32.
